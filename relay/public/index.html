    Các phiên xem / điều khiển máy của bạn đã kết thúc, mới nhất trước.

      Cài RemoteDesk lên máy tính

      Agent + App: máy được điều khiển, và có app RemoteDesk để điều khiển máy khác. Chỉ agent: máy chỉ để được điều khiển (điều khiển nó từ trình duyệt / iPhone).

      Bộ cài dùng chung cho mọi người. Khi cài, nhập mã truy cập: máy vào nhóm máy của mã đó, và ai đăng nhập bằng mã đó sẽ điều khiển được. Chạy lại bộ cài và nhập mã khác để chuyển máy sang nhóm khác.

      ⊞ Windows

      Tải bộ cài · Agent + App Tải bộ cài · Chỉ agent
      1. Bấm đúp file vừa tải. Nếu hiện “Windows protected your PC”: More info → Run anyway.
      2. Yes khi hỏi quyền Admin → Tiến → nhập mã truy cập → Cài đặt → Hoàn thành.
      3. Cài đè lên bản cũ được, máy giữ nguyên tên. Gỡ: Settings › Apps › RemoteDesk.

      macOS

      Tải bộ cài · Agent + App Tải bộ cài · Chỉ agent
      1. Bấm đúp file .pkg. Nếu macOS chặn: System Settings › Privacy & Security › Open Anyway.
      2. Continue → Install (nhập mật khẩu Mac) → nhập mã truy cập.
      3. Bật RemoteDesk trong Screen & System Audio Recording và Accessibility (chỉ lần đầu).

      Cần ffmpeg — bộ cài tự cài qua Homebrew nếu máy có Homebrew.

        Mật khẩu admin

        Đăng nhập trang này bằng mật khẩu của bạn thay cho token admin dài (token admin vẫn dùng được). Ít nhất 10 ký tự.
