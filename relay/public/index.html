RemoteDesk

Nhập mã truy cập một lần — trình duyệt sẽ nhớ.

Cài lên máy cần điều khiển (bộ cài sẽ hỏi mã truy cập):
Windows · macOS — kèm app điều khiển: Windows · macOS

RemoteDesk

Quản lý người dùng Đăng xuất

    Chưa có máy nào online. Cài agent lên máy cần điều khiển.

    Chưa có Pi nào online. Thêm Pi bằng lệnh bên dưới.

    Chưa có điện thoại nào online. Cài app RemoteDesk cho Android theo hướng dẫn bên dưới.

    Thêm điện thoại Android

    Làm một lần trên chính điện thoại cần điều khiển (Android 8 trở lên). Điện thoại tự kết nối ra máy chủ, nên sau đó điều khiển được từ bất cứ đâu.

    Tải app RemoteDesk (APK)
    1. Mở link trên bằng trình duyệt của điện thoại → tải về → mở file. Nếu Android hỏi, cho phép trình duyệt cài ứng dụng không rõ nguồn.
    2. Mở app RemoteDesk → nhập mã truy cập (giống khi cài cho máy tính) → Lưu và kết nối.
    3. Cho phép chụp màn hình: tích “Không hiển thị lại” → Bắt đầu ngay.
    4. Bật Trợ năng → RemoteDesk (để chạm, vuốt, gõ chữ từ xa) và Cho chạy nền liên tục.
    5. Khoá màn hình để Vuốt hoặc Không: có mã PIN thì từ xa không mở khoá được.

    App tự chạy lại khi điện thoại khởi động lại. Có thể bật luôn Loa BirdMonitor trong app để thay trang Loa trên Chrome.

    Thêm Pi

    Chạy một lần trên Pi (qua SSH hoặc bàn phím cắm vào Pi). Pi tự kết nối ra máy chủ, nên sau đó quản lý được từ bất cứ đâu, không cần IP public hay chung mạng. Chạy lại lệnh để cập nhật; cấu hình ở /etc/remotedesk-pi/config.json.

    Lệnh trên có chứa mã truy cập của bạn. Lệnh không kèm mã (Pi sẽ hỏi mã khi cài):

    Hỗ trợ Pi 3/4/5, Zero 2 (64-bit) và Pi Zero / Pi 1 (32-bit).

    Lịch sử truy cập

    Các phiên xem / điều khiển máy của bạn đã kết thúc, mới nhất trước.

      Cài RemoteDesk lên máy tính

      Agent + App: máy được điều khiển, và có app RemoteDesk để điều khiển máy khác. Chỉ agent: máy chỉ để được điều khiển (điều khiển nó từ trình duyệt / iPhone).

      Bộ cài dùng chung cho mọi người. Khi cài, nhập mã truy cập: máy vào nhóm máy của mã đó, và ai đăng nhập bằng mã đó sẽ điều khiển được. Chạy lại bộ cài và nhập mã khác để chuyển máy sang nhóm khác.

      ⊞ Windows

      Tải bộ cài · Agent + App Tải bộ cài · Chỉ agent
      1. Bấm đúp file vừa tải. Nếu hiện “Windows protected your PC”: More info → Run anyway.
      2. Yes khi hỏi quyền Admin → Tiến → nhập mã truy cập → Cài đặt → Hoàn thành.
      3. Cài đè lên bản cũ được, máy giữ nguyên tên. Gỡ: Settings › Apps › RemoteDesk.

      macOS

      Tải bộ cài · Agent + App Tải bộ cài · Chỉ agent
      1. Bấm đúp file .pkg. Nếu macOS chặn: System Settings › Privacy & Security › Open Anyway.
      2. Continue → Install (nhập mật khẩu Mac) → nhập mã truy cập.
      3. Bật RemoteDesk trong Screen & System Audio Recording và Accessibility (chỉ lần đầu).

      Cần ffmpeg — bộ cài tự cài qua Homebrew nếu máy có Homebrew.
